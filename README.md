# Marchica Trips

Site web responsive et accessible pour une agence proposant des activités autour de la lagune de Marchica, à Nador.

## Pages

- Accueil
- Activités
- Détail d’une activité
- Réservation
- FAQ

## Technologies

- Vite
- Tailwind CSS v4
- HTML sémantique
- CSS Grid et Flexbox

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Design et accessibilité

Le thème visuel est défini dans Tailwind CSS avec `@theme`. Le site adopte une approche mobile-first et vise une navigation complète au clavier, un focus visible et des contrastes conformes au niveau WCAG AA.

## Équipe

Projet réalisé en équipe Squad dans le cadre du Brief 2. Chaque membre contribue au code et aux revues de Pull Requests.
